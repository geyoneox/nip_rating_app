# NIP Rating test cases

Manual test plan. Use synthetic data only (no real insured, driver or licence details). Status: not run yet.

| # | Test | Steps | Expected result |
|---|------|-------|-----------------|
| 1 | Upload and extraction | Upload a fake tabbed application (PDF or Excel) with 3 vehicles, 2 IM items and 2 drivers. Wait for extraction to finish. | A new run appears with the status Extracted. Exactly 3 vehicles, 2 IM items and 2 drivers are saved, and the insured fields are filled. A trailer row is marked (TRAILER). |
| 2 | Duplicates and skipped VINs | Use a file with 2 blank VINs, 1 placeholder (NEED), 1 invalid VIN (16 characters), 1 trailer and 2 rows with the same VIN. Open the AUTO tab and look at the dashboard. | The dashboard counts match: blank/placeholder 3, invalid 1, trailers 1, duplicates 1. Only the unique, valid, non-trailer VINs are queued for validation. |
| 3 | VIN validation run | Click Validate VINs (PriceDigest) on a run with 5 good VINs (use a test scraper if no real access yet). | Progress goes 1/5 to 5/5 and the status becomes Complete. The PriceDigest columns fill in. A VIN that fails appears under its failure reason. Trailers show "Tabbed app only". |
| 4 | Stop and retry validation | Start validation on 10 VINs and click Stop Validation partway. Then click Retry Failed, and separately validate 2 selected rows. | Status becomes Cancelled and finished results are kept. Retry sends only the failed VINs. Validate Selected sends only the 2 ticked rows and leaves the other results alone. Starting validation twice is refused with "VIN validation is already running". |
| 5 | Class code and original cost new | After validation, check the Class Code and OCN Value columns. Use these checks: truck GVW 12,000 in OH gives 21489, and in TX gives 23589. A dump truck GVW 25,000 in OH gives 31479. Cost 50,000 with MSRP 60,000 gives OCN 60,000. An Incomplete vehicle with MSRP 100,000 and cost 90,000 gives 133,000. A trailer with cost 8,000 and MSRP 20,000 gives 8,000. | All values match. Changing the Program Name or editing cost new refreshes the values. Also run worked examples 1 to 15 from `docs/rating-rules.md` section 5. |
| 6 | Deductibles and IM rules | Check these cases: comp/OTC "Yes" with OCN 40,000 gives a 1,000 deductible; collision "Yes" with OCN 75,000 gives 2,000; with OCN 120,000 gives 5,000; a trailer always gives 1,000. IM: a crane gives 2,500; limit 300,000 gives 10,000; limit 150,000 gives 5,000; limit 99,999 gives 1,000 for Treepro or Landpro and 2,500 for other programs. | Every deductible matches. Small-tool items are left off the IM schedule. Also run worked examples 16 to 20 from `docs/rating-rules.md` section 5. |
| 7 | Exports | Edit one cell, then click Export BA Worksheet, Export IM Worksheet and Export Drivers CSV. Open each file. | BA: rows start at row 6 and are numbered 1, 2, 3. Make and model are in capitals, the zip is 5 digits, and class code 03589 keeps its leading zero. Duplicates are left out. IM: missing years show Need and missing serials show Needed. Drivers CSV: the columns are in order, names are cleaned, the licence number has only letters and digits, Product Billing Code is 000, and every value is quoted. Your edit appears in the file. The template logo, dropdowns and all sheets are intact. |
| 8 | Access and delete | As user_a, upload a run. As user_b, try to open it by link, validate it and export it. As a reviewer, open and export it, but try to edit and delete. As user_a, delete the run. | user_b is denied everything. The reviewer can view and export but not edit, validate or delete. After delete, the run, all its rows and its files are gone. |
